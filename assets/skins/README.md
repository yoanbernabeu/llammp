# Skins

This folder ships empty on purpose.

Winamp skins (`.wsz`) are third-party artwork owned by their respective authors, so
Llammp does not redistribute any of them.

Drop any `.wsz` file here, or — much easier — drag it straight onto the Llammp window.
Skins added that way are copied to your personal folder and survive updates:

    ~/Library/Application Support/llammp/skins

## Where to get skins

- **Winamp Skin Museum** — <https://skins.webamp.org> — tens of thousands of classic
  skins, searchable, one click to download.
- **Internet Archive: Winamp Skins** — <https://archive.org/details/winampskins>
- **Winamp.com skins** — <https://www.winamp.com/skins>

Classic Winamp 2 skins are what Llammp targets. Modern (Winamp 3/5 `.wal`) skins are a
different format and are not supported.
